# Apartamento en Primera Línea de Playa

    Este proyecto es una página web que muestra un apartamento en primera línea de playa. La página incluye una galería de imágenes que se comporta de manera diferente en dispositivos móviles y en dispositivos de escritorio/tabletas.

## Nota importante

    Uso de `window.onload` en lugar de `DOMContentLoaded` en `lightboxMobile.js`.
